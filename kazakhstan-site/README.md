# Сайт о Казахстане

Этот сайт представляет краткую информацию о Казахстане. Он содержит страницу `index.html` со стилями из `style.css`.

## Как запустить

1. Откройте терминал и перейдите в каталог `kazakhstan-site`:
   ```bash
   cd kazakhstan-site
   ```
2. Запустите простой веб‑сервер Python:
   ```bash
   python3 -m http.server 8000
   ```
3. Откройте браузер и перейдите по адресу `http://localhost:8000`.

Также вы можете просто открыть файл `index.html` двойным щелчком мыши, однако использование веб‑сервера удобнее при работе с несколькими файлами.
